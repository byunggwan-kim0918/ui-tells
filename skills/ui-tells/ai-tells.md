# AI Tells — 검증 체크리스트

§8 검증 4번에서 이 파일을 연다. **렌더된 화면과 코드를 이 목록으로 훑는다.**
`grep` 가능한 항목은 기계적으로 세고, 나머지는 스크린샷을 보고 판정한다.
걸리면 묻지 말고 고치고 다시 렌더한다.

> 이 목록은 taste-skill §9(AI TELLS)를 대체하지 않고 **보강**한다. taste-skill이 안 잡는 항목이 여기 다수 있다.

**기계 체크는 `audit.sh`가 대신한다**: `bash <이 폴더>/audit.sh <소스경로...>`
이 파일의 역할은 **grep으로 못 잡는 것**을 사람 눈으로 판정하는 것이다 — 채도가 균질한가, accent에 위계가 있는가,
스크롤하며 밀도가 변하는가, 각 모션이 무엇을 전달하는가. 스크립트가 통과해도 여기서 걸릴 수 있다.

**오탐 주의**: 정규식은 반드시 실체를 확인한다. 실제로 겪은 것 -
`Inter`가 `interface`·`INTERVAL`에 매치됨 / `py-2`가 섹션 리듬이 아니라 버튼 패딩이었음.
오탐을 발견하면 audit.sh를 그 자리에서 고친다.

**예외**: 지도·차트의 **카테고리 색**은 "accent 3개 이상" 규칙에서 제외한다(구분이 기능이다).
다만 Tailwind 기본 무지개를 그대로 쓰는 건 여전히 tell — 브랜드 안에서 구분 가능하게 설계할 것.

## 1. 컬러

- [ ] 보라-파랑 그라데이션(`#6366f1` → `#a855f7` 계열)이 hero 배경이나 gradient text에 있다
- [ ] Tailwind 기본 팔레트를 그대로 씀 (`slate-50` 배경 + `indigo-600` 버튼)
- [ ] **accent가 3개 이상인데 위계가 없다** — 어느 게 주인지 화면에서 안 보이면 실패
- [ ] **채도가 전부 비슷한 중간값** — 아주 탁한 색도, 아주 쨍한 색도 없다. 팔레트가 밋밋하게 균질하면 실패
- [ ] **다크모드가 색 반전 수준** — `#0f172a` 고정 배경, 라이트의 값을 뒤집기만 함
- [ ] 브랜드 색이 아니라 "예쁜 색"을 씀 — 이 색인 이유를 한 문장으로 못 대면 실패

기계 체크: `grep -rE '#6366f1|#a855f7|#0f172a|slate-50|indigo-600'`

## 2. 타이포그래피

- [ ] Inter / Poppins, 한글이면 Noto Sans KR
- [ ] **serif·mono를 아예 안 씀** — sans 한 종류로만 전부 처리
- [ ] **위계 차이가 소심하다** — 제목 36px / 본문 16px 수준. 대비가 2배 미만이면 위계가 아니라 크기 차이일 뿐
- [ ] **`letter-spacing`·`line-height` 조정 흔적이 없다** (전부 기본값)
- [ ] 제목이 gradient text + `font-bold`
- [ ] **문단 폭이 화면 끝까지 늘어난다** (`max-w` 미관리). 본문은 65ch 근처에서 끊는다
- [ ] **숫자에 `tabular-nums`를 안 씀** — 가격·통계·타이머가 흔들린다

기계 체크: `grep -rE 'Inter|Poppins|Noto Sans KR'` / `grep -c 'tracking-\|leading-'` / `grep -c 'tabular-nums'`

## 3. 레이아웃

- [ ] **섹션 순서가 고정 템플릿** — hero(중앙정렬) → feature 3열 → testimonial → CTA → footer
- [ ] **모든 섹션이 같은 높이** (`py-20` 반복). 리듬이 없다
- [ ] **grid가 항상 3열 아니면 2열** — 4:6, 7:5 같은 비대칭 분할이 없다
- [ ] 좌우 여백이 항상 대칭
- [ ] **스크롤해도 밀도 변화가 없다** — 처음부터 끝까지 같은 호흡
- [ ] 정보 위계가 없어 무엇을 먼저 볼지 모르겠다

기계 체크: `grep -o 'py-[0-9]*' | sort | uniq -c` (한 값이 압도적이면 리듬 없음)
`grep -o 'grid-cols-[0-9]' | sort | uniq -c` (2·3만 있으면 비대칭 없음)

## 4. 컴포넌트

- [ ] 카드가 전부 `rounded-2xl` + `shadow-lg` + `p-6` + `border border-gray-200` 세트
- [ ] **모든 카드 높이가 강제로 동일**
- [ ] **카드마다 원형(또는 사각) 배경 안에 아이콘 1개** — 이 패턴이 반복되면 템플릿
- [ ] 버튼이 pill + gradient + `hover:scale-105`
- [ ] glassmorphism(`backdrop-blur` + 반투명 흰색)을 이유 없이 씀
- [ ] **아이콘 사이즈가 전부 동일** (`w-6 h-6`) — 위계에 따라 달라져야 한다
- [ ] **그림자가 광원 방향과 무관하게 사방으로 퍼짐** — 실제 조명이라면 방향이 있다
- [ ] **브랜드색 그림자(글로우)** — `shadow-[...var(--accent)]`. accent가 채도 높은 색으로 바뀌는 순간 네온이 된다.
      그림자는 빛이 막힌 자리지 발광이 아니다. 중립(배경 hue의 잉크)으로 쓴다

기계 체크: `grep -c 'hover:scale-'` / `grep -o 'size={[0-9]*}' | sort | uniq -c` / `grep -c 'backdrop-blur'`

- [ ] **시맨틱 토큰 오용** — 상태색(완료·에러·경고)을 상태가 아닌 데이터에 빌려 쓴다.
      별점에 '완료 초록', 개수에 '경고 주황' 같은 것. 팔레트에 없는 색이 튀어 보이는 주원인이다.
      상태가 아닌 것은 중립색(foreground/text-2/muted)으로 표시한다

## 5. 콘텐츠 (디자인 요소로서)

- [ ] 섹션 제목 앞에 이모지 (🚀 ✨ 💡)
- [ ] corporate memphis 일러스트
- [ ] 이미지 자리에 `/api/placeholder/400/300` 또는 회색 박스
- [ ] 더미 데이터가 "Acme Inc / John Doe / $99 per month"
- [ ] 통계가 "10,000+ users", "99.9% uptime"
- [ ] 아바타가 Unsplash 인물 사진

기계 체크: `grep -rE '🚀|✨|💡|Acme|John Doe|99\.9%|10,000\+|api/placeholder'`

## 6. 모션

- [ ] **모든 요소가 같은 duration·같은 easing의 fade-in + translate-y** — 하나의 효과를 전부에 복사
- [ ] hover에 무조건 `scale` + shadow 증가
- [ ] easing이 `ease-in-out` 기본값, custom cubic-bezier 없음
- [ ] **애니메이션에 목적이 없다** — 각 모션이 무엇을 전달하는지 한 문장으로 못 대면 뺀다
      (유효한 목적: 위계·서사·피드백·상태 전환. "움직이니까 좋아 보여서"는 목적이 아니다)

기계 체크: `grep -o 'animation:[^]]*' | sort | uniq -c` (한 값만 나오면 전부 동일)

## 7. 실전에서 반복해 나온 것

_근거가 궁금하면 [lessons.md](lessons.md)._

- [ ] **폴백 시각요소가 팔레트를 압도** — 사진 없을 때의 그라데이션 커버가 화면에서 가장 시끄러우면 팔레트가 무너진다
- [ ] **한 토큰이 배경과 텍스트 양쪽에 쓰임** — 배경 기준(흰 텍스트 대비)만 맞추면 텍스트 기준이 깨진다
- [ ] **토큰을 바꿨는데 그 토큰에 의존하는 것들을 전수 조사 안 함** — 그라데이션 짝값·컬러 그림자·시맨틱 오용이
      한꺼번에 어긋난다. accent를 바꿀 땐 `linear-gradient`·`shadow-[...var(--accent)]`·상태색 차용을 모두 grep한다
- [ ] **접힘선 아래 요소에 로드 시점 애니메이션** — 스크롤해 오기 전에 끝나 아무도 못 본다
- [ ] **성공 경로만 렌더** — 에러·로딩·빈 상태를 실제로 트리거해서 보지 않았다
- [ ] **오버레이 자리 미확인** — 레이아웃을 바꾸고 토스트·모달이 콘텐츠 위에 겹치는지 안 봤다
- [ ] **이니셜 사각형 로고** — 둥근 사각형에 글자 하나는 로고가 없을 때 채우는 플레이스홀더다.
      실제 마크가 프로젝트에 이미 있는지 먼저 확인한다(파비콘·에셋 폴더)
- [ ] **테마 전략 혼용** — Tailwind `dark:` 변형과 `.dark` 클래스 토큰을 섞으면 한쪽은 OS를, 다른 쪽은 클래스를 따라 어긋난다
- [ ] **기계 생성 텍스트를 사람 카피처럼 조판** — LLM·API가 만드는 제목은 60자 넘는 문장인데
      display 크기에 `truncate`를 걸면 정보도 잃고 시끄럽기만 하다. DB 실값으로 길이를 확인하고,
      길면 display 크기를 쓰지 않고 `truncate`(1줄)보다 `line-clamp-2`를 쓴다.
      **고정 높이 컨테이너 안에서 clamp가 없으면 형제 요소를 밖으로 밀어낸다** (근거 L12)
- [ ] **반복되는 API 원문을 그대로 나열** — 같은 값이 7번 반복되고 잘린 채 끝나면 한 줄을 다 쓰면서 정보량은 0이다.
      조판이 아니라 **압축**으로 푼다(같은 값 묶기). 원문은 `title` 속성에 남긴다 (근거 L20)
